## 📑 7 Core Pages Built
1. **Home (`/`)**:
   - Announcement Bar with vision status and quick links
   - Sticky Navigation with search, mega dropdown, and "Join Network" CTA
   - High-impact Split Hero with international trade collage and bilateral corridor nodes
   - 4 Foundation Pillars highlighting 62 categories & 57 countries vision metrics
   - 17 Starter Business Categories Grid with distinctive color badges and direct directory drilldown
   - Interactive Global Business Network with real-time country selector and market dossier
   - BUY, SELL, TRADE, CONNECT & GROW: 5 interactive simulation modals
   - Industries We Serve visual showcase
   - Upcoming Exhibitions & Trade Fairs with booth booking
   - 4-Step "How It Works" workflow
   - Founder statement and charter
   - Full Lead & Partnership Capture Form with client validation
   - Comprehensive footer with legal draft modals
2. **Industries Directory (`/industries`)**:
   - Real-time search across categories, sub-sectors, and offerings
   - Sector filtering: Industrial & Infrastructure, Consumer & Lifestyle, Global Trade & Logistics, Technology & Consulting
   - Detailed category cards with sample offerings, listing volumes, and RFQ triggers
3. **Business Directory (`/directory`)**:
   - Search by company name, products, or specifications
   - Multi-faceted filters: 17 Industry Verticals & 57 Countries
   - Sample verified business cards with "DEMO LISTING" badges
   - Company Dossier Modal ("View Details")
   - Direct RFQ / Enquiry Modal ("Send Enquiry")
4. **Global Network (`/global-network`)**:
   - Interactive 57-country international trade directory
   - Continental filtering: Africa, Asia-Pacific, Middle East, Europe, Americas
   - Country trade dossier with major trade sectors, bilateral opportunity notes, and corridor enquiry trigger
5. **Exhibitions & Events (`/events`)**:
   - Flagship buyer-seller meets, B2B conclaves, and hybrid trade expos
   - Filter by format (In-Person, Conclave, Virtual Hybrid)
   - Program Details inspection modal
   - Booth & Delegate Booking Enquiry Form
6. **About Us (`/about`)**:
   - Founding vision, Kumud Gameti profile, and core principles
   - 3-Phase Vision Roadmap: Interactive Demo, Accredited Onboarding, Cross-Border Escrow & Expos
7. **Contact (`/contact`)**:
   - Full contact form with validation and instant feedback
   - Secretariat coordinates and regional hubs
   - Direct link to the real-time Demo Leads Drawer

## 🚀 How to Run Locally

```bash
cd aura-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To run a production build:
```bash
npm run build
npm start
```

## ⚡ Functional Demo Features
- **Client-Side Persistence:** Form submissions are saved in browser `localStorage` under `indiniger_demo_enquiries`.
- **Demo Leads Drawer:** Click the **"Demo Leads"** pill in the top header or on the Contact page to view, inspect, and export all submitted demo leads in real-time.
- **Confetti Celebrations:** Dynamic feedback triggered upon successful form submission.
- **Zero Paid Dependencies:** Runs completely offline and locally without requiring external paid APIs or subscription keys.
